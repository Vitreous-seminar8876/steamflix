## 🛠️ Troubleshooting

**Problem: The app won't open.**
- Make sure you have the latest version of Windows.
- Try right-clicking the steamflix icon and selecting **"Run as administrator."**

**Problem: Downloads are slow.**
- Check your internet connection.
- Pause other downloads or streaming services.

**Problem: Game crashes on launch.**
- Right-click the game's `.exe` file → **Properties** → **Compatibility** → Try different compatibility modes (Windows 98, XP, etc.).
- Run the game in **Windowed mode** if fullscreen causes issues.

**Problem: No sound in games.**
- Some old games need special audio settings. Look for an "Audio Setup" or "Sound Options" menu inside the game and select your sound card.
